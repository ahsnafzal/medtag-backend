================================================================================
                        TROUBLESHOOTING
================================================================================

Build fails?
  → Check requirements.txt is complete
  → Rebuild: Vercel Dashboard → Deployments → Redeploy

Static files 404?
  → Verify STATIC_ROOT = staticfiles
  → Check static file collection ran

Database timeout?
  → Verify DB_HOST includes full URL
  → Check DB_PASSWORD is correct

CORS errors?
  → Add your frontend domain to CORS_ALLOWED_ORIGINS
  → Use https:// prefix

Email not working?
  → Use Gmail App Password (16 chars), not main password
  → Verify EMAIL_HOST_USER is correct

File uploads issue?
  → Files stored locally on Vercel (normal)
  → Add AWS S3 later if needed
